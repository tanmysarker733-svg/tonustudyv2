CORE RULE
Use the n+1 rule for numbered web files: copy the latest hsc-study-os__NNN_.html to
the next number, then edit the new file only. Never overwrite prior versions.

ANDROID
- Android wrapper source: app\
- Android is a live WebView wrapper around https://tonustudy.vercel.app/ so the
  deployed index.html remains the single UI/feature source for web and APK.
- With no network, the wrapper shows a connection warning and supports pull-to-retry;
  it does not ship a second stale offline HTML interface.
- Native Android owns Google account selection, file picking, app-aware Back handling,
  external links, connectivity checks, and the compact launch screen.
- Increase versionCode and versionName in app\build.gradle.kts for every release.

WEB 372 NOTES
- Account Security has one responsive scroll surface, clearer provider states,
  keyboard submission, a correctly placed password visibility control, and
  balanced dark/light styling.
- SKIP users can create a recoverable Firebase username/password account from
  the Security panel without discarding their local study progress. The first
  cloud snapshot is queued immediately after successful account creation.
- Local-only SKIP/admin sessions no longer expose a stale Firebase provider
  state from a previous browser session.

WEB 371 NOTES
- A Firebase user can set or change a username/password login in Account >
  Security. It links to the current Firebase UID, including Google-created
  accounts, so cloud progress remains attached to one account.
- The username uses a private Firebase Auth email alias. Passwords are managed
  only by Firebase Authentication and must never be stored or displayed by the
  page.
- Phone/SMS linking remains disabled and visually marked unavailable.
- Firestore rules are maintained in firestore.rules; firebase.json and
  .firebaserc point the Firebase CLI to project tonustudy.
- Narrow notifications, account close placement, spectate status, and Smart
  Update layout were compacted without adding expensive blur effects.

WEB 370 NOTES
- Native Animation defaults off on mobile/Android until the user explicitly
  enables it.
- Chapter slider input is requestAnimationFrame-batched to avoid redundant
  rerenders, and narrow login/composer controls no longer clip labels.

WEB 363 NOTES
- Smart Update uses subject icons for Physics, Chemistry, Biology, Higher Math,
  and ICT; other subjects and free-text topics retain the standard play icon.
- Detailed is implicit and omitted. One Shot, Advanced, and Admission render as
  O-shot, Adv., and Adm.; lecture notation renders as Lec.
- Smart Sync continues to accept both legacy and compact lecture/class labels.

WEB 362 NOTES
- Native Animation controls rich mobile/Android feedback without forcing the
  costly legacy performance profiles.
- Settings, mission, install, and fullscreen-composer dialogs share one
  scroll-lock/restore path to prevent frozen pages and pull-to-refresh conflicts.
- Sliders, font scaling, and theme changes update smoothly without full-page
  rendering on every input event.
- Tablet quick tools expose readable labels; browser install choices and Android
  update checks use the shared GitHub release channel.

SYNC LIMITATION
Browser local storage and Android WebView local storage are separate. Real cross-device
sync requires a configured authenticated cloud backend/API. Never claim sync works
unless remote save and restore are tested.
